# lg-podium
Louis Gabor TOP-3 podium picture (approved design X01).
- `python3 publish.py render data.json <name>` — render + push, prints RAW_URL
- `python3 publish.py cleanup <name>` — remove the picture after it was sent
Examples of data: `week.json`, `month.json`. Pictures must not stay in `out/` (public repo).
